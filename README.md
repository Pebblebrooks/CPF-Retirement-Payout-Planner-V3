CPF Planner Pro - Web Application

Welcome to the main application repository for CPF Planner Pro. This is a privacy-first, client-side React application built with Vite, designed to help Singaporeans calculate, project, and optimize their Central Provident Fund (CPF) retirement strategies.

🔗 Live Links

Main Web Application: https://cpfplannerv3.netlify.app/

Marketing & Promo Site: https://cpfplannerhome.netlify.app/

📖 Project Overview

CPF policies are complex, with varying interest rates, contribution ceilings, and milestone rules (e.g., Age 55 transfers, Basic Healthcare Sum limits).

This application provides a visual, interactive dashboard to simplify these policies. Users can input their current balances and salary to instantly generate long-term projections, compare standard vs. optimized scenarios, and plan for housing deductions or voluntary account transfers.

✨ Core Features

Real-Time Visual Projections: Dynamic charts that instantly update as users tweak their salary, age, and retirement targets.

Scenario Simulations: Test the impact of buying a property (OA deductions) or making voluntary transfers (OA to SA) on final retirement payouts.

Milestone Automation: Automatically accounts for age-based contribution rate drops and the creation of the Retirement Account (RA) at age 55.

100% Privacy-Focused: All state and calculations are managed client-side in the browser. Zero financial data is collected, transmitted, or stored on external servers.

🚀 Local Development Setup

To run this project locally on your machine for development or testing:

Prerequisites

Make sure you have Node.js installed (v16 or higher is recommended).

Installation

Clone the repository:

git clone [https://github.com/your-username/cpfplannerv3.git](https://github.com/your-username/cpfplannerv3.git)
cd cpfplannerv3


Install dependencies:

npm install


Start the local development server:

npm run dev


The app will usually be available at http://localhost:5173

Build for production:

npm run build


This command generates the optimized static files in the dist folder.

📁 Repository Architecture Note

To ensure the best performance and maintain a clean build process, the CPF Planner Pro ecosystem is split into two repositories:

This Repository (The App): The React/Vite web application that handles the complex financial calculations and interactive dashboard.

The Promo Repository: A static HTML/CSS landing page optimized for SEO and marketing, which funnels users to this application.
